# Keele University Strategy Dev Site

A static preview site for Keele University's strategy content, including the homepage overview (priorities, pillars, roadmap) and the full strategy text.

**Live site (GitHub Pages):** https://bearduk.github.io/keele-strategy-dev/

Note: `robots.txt` blocks well-behaved crawlers from indexing this preview.

## Structure

- `index.html` — homepage with priorities, pillars, and roadmap sections
- `full-strategy.html` — full strategy text
- `styles.css` / `script.js` — shared styles and behaviour
- `brand-logo.svg` — Keele University logo
